## 📖 Introduction

CodeGenTool is an IntelliJ IDEA plugin for Java developers, dedicated to automating repetitive and template-based code generation, improving development efficiency and code standardization.

Currently implemented features:

✅ **Automatic `isXXX()` method generation for enum classes** - Automatically generate type-safe predicate methods for each enum constant
✅ **Enum Consistency Check** - Compare enums across different branches, detect value conflicts and duplicate values, support real-time inspection
✅ **Reverse Enum Lookup** - Generate null-safe `Optional` lookup methods with default-value fallback

## ✨ Features

### Enum `isXXX()` Method Generation

Automatically generate `isXXX()` predicate methods for enum classes, supporting two modes:

1. **Instance comparison mode** - Directly compare enum instances for equality
2. **Field comparison mode** - Compare based on the value of a specified field (supports `@EqualsField` annotation customization)

**Example output:**

```java
public enum Gender {
    MALE(1, "Male"),
    FEMALE(2, "Female");

    private final int code;
    private final String desc;

    Gender(int code, String desc) {
        this.code = code;
        this.desc = desc;
    }

    // 👇 The following methods are automatically generated by the plugin
    public boolean isMale() {
        return this == MALE;
    }

    public boolean isFemale() {
        return this == FEMALE;
    }

    public int getCode() {
        return code;
    }

    public String getDesc() {
        return desc;
    }
}
```

## 🚀 Installation

### Install from JetBrains Marketplace (Recommended)

1. Open IntelliJ IDEA
2. Go to `Settings/Preferences` → `Plugins` → `Marketplace`
3. Search for **CodeGenTool**
4. Click `Install` and restart IDE

### Manual Installation

1. Download the latest `.zip` package from [Releases](https://github.com/coder-knock/CodeGenTool/releases)
2. Go to `Settings/Preferences` → `Plugins` → `⚙️` → `Install Plugin from Disk...`
3. Select the downloaded zip package
4. Restart IDE

## 📖 Usage

### Generate `isXXX()` Methods for Enums

1. Open a Java enum class in the editor
2. Right-click in the editor's blank area
3. Select `CodeGen` → `Generate isXXX Methods` from the menu
4. The plugin will automatically generate `isXXX()` methods at the end of the enum class

### Custom Field Comparison

If you want to compare based on a field value instead of instance comparison, you can use the `@EqualsField` annotation to specify:

```java
public enum Gender {
    MALE(1, "Male"),
    FEMALE(2, "Female");

    @EqualsField
    private final int code;
    private final String desc;

    Gender(int code, String desc) {
        this.code = code;
        this.desc = desc;
    }

    // 👇 The plugin will generate based on the code field
    public boolean isMale(int code) {
        return this.code == code;
    }

    public boolean isFemale(int code) {
        return this.code == code;
    }
}
```

> **Note:** If an enum has multiple fields and `@EqualsField` is not specified, the plugin will default to selecting the first non-static field for comparison.

### Generate Reverse Lookup Methods

Right-click in an enum file and choose `CodeGen` → `Generate Enum Lookup Methods`. The plugin uses the
field marked with `@EqualsField`, or the first instance field when no field is marked.

```java
public static Optional<Gender> fromCode(int code) {
    return Arrays.stream(values())
            .filter(candidate -> candidate.code == code)
            .findFirst();
}

public static Gender fromCodeOrDefault(int code, Gender defaultValue) {
    return fromCode(code).orElse(defaultValue);
}
```

Object fields are compared with `Objects.equals`, so nullable values are safe. Running the generator repeatedly does not create duplicate methods.

### Enum Consistency Check

When multiple branches develop enums in parallel, conflicts such as enum constant value collisions and duplicate values can easily occur. The plugin provides three ways to check:

#### 1. Quick Compare Current Enum (Single File Compare)
1. Open the enum you want to compare in the editor
2. Right-click → `CodeGen` → `Compare Current Enum with Branch`
3. Select the target branch to compare, click OK
4. A dialog will pop up showing the comparison results

#### 2. Full Project Batch Compare
1. Right-click on the project or folder → `CodeGen` → `Compare All Enums with Branch`
2. Select the target branch to compare
3. Scan the entire project in background and display all inconsistent enums

#### 3. Real-time Inspection (Recommended)
Check `Enable real-time consistency check` in the comparison dialog, when editing enums later IDE will:
- Automatically compare current enum with target branch
- Highlight inconsistent enum constants in real-time
- Prompt problems directly in editor, no manual comparison needed

**Check Items:**
| Item | Description |
|--------|------|
| Value Mismatch | Same constant has different values on both sides |
| Missing in Local | Constant exists in remote but not in local |
| Missing in Remote | Constant exists in local but not in remote |
| Duplicate Value | Multiple constants use the same value in local |

**Advantages:**
- 🔐 Fully compatible with IDEA Git authentication, **native SSH key support**
- 🔄 Reuse IDEA's existing Git configuration, no extra configuration needed
- ⚡ Background asynchronous scanning, does not block editing

## 🏗️ Build from Source

### Requirements

- JDK 17+
- Gradle 8+ (Gradle wrapper is included in the project)

### Build Steps

```bash
# Clone the project
git clone https://github.com/coder-knock/CodeGenTool.git
cd CodeGenTool

# Build the plugin package
./gradlew buildPlugin

# The output will be generated at build/distributions/CodeGenTool-<version>.zip
```

### Development Debugging

```bash
# Start a new IDE instance for debugging
./gradlew runIde
```
