# 枚举一致性检查使用指南

## 功能介绍

在团队并行开发中，多个分支同时维护同一个枚举是很常见的场景。不同分支可能会：
- 添加相同值的不同常量导致值冲突
- 互相添加了对方没有的常量
- 在同一个枚举中出现重复的值

这些问题如果不及时发现，合并后很容易产生线上 bug。**枚举一致性检查** 功能就是为了帮助开发者在合并前就能发现这些问题。

## 核心特性

| 特性 | 说明 |
|------|------|
| 🌲 **多分支对比** | 支持将当前代码与任意本地/远程分支对比 |
| 🔍 **全项目扫描** | 一键扫描整个项目找出所有不一致的枚举 |
| ⚡ **实时检查** | 启用后编辑代码时 IDE 自动高亮问题 |
| 🔐 **SSH 兼容** | 完全复用 IDEA 的 Git 认证配置，原生支持 SSH 密钥 |
| 🎯 **精准检测** | 检测值冲突、常量缺失、重复值多种问题 |

## 使用方式

### 方式一：快速对比当前枚举

当你正在编辑一个枚举，想要快速确认是否和目标分支（如 `main`/`master`）有冲突：

1. 在编辑器中打开该枚举
2. 右键点击 → `CodeGen` → `Compare Current Enum with Branch`
3. 输入/选择目标分支
4. 查看对比结果

### 方式二：全项目批量对比

在合并前想要检查整个项目所有枚举和目标分支是否一致：

1. 在项目视图右键点击项目/模块 → `CodeGen` → `Compare All Enums with Branch`
2. 选择目标分支
3. 等待后台扫描完成
4. 对话框会显示所有不一致的枚举

### 方式三：启用实时检查

如果你需要长时间在特性分支开发，想要每次编辑都自动检查：

在批量对比对话框中勾选 **Enable real-time consistency check**，之后：
- 每次你编辑枚举文件，IDEA 都会自动对比
- 如果有不一致，会直接在编辑器中高亮显示问题
- 你可以在 **Inspection Results** 面板看到所有问题

## 检测规则

插件会检测以下几种问题：

### 1. 值不匹配 (Value Mismatch)

同一个枚举常量在两个分支中有不同的值：

```java
// 分支 main
public enum Status {
    ACTIVE(1),  // 值是 1
    INACTIVE(2);
}

// 分支 feature
public enum Status {
    ACTIVE(10), // 值变成了 10 ❌ 冲突
    INACTIVE(2),
    PENDING(1);  // PENDING 使用了 1，和 ACTIVE 重复 ❌
}
```

### 2. 本地缺失常量 (Missing in Local)

目标分支有这个常量，当前分支没有：
- 提示开发者可能需要合并新增的常量

### 3. 远端缺失常量 (Missing in Remote)

当前分支有这个常量，目标分支没有：
- 确认这是你要新增的常量，这是正常的

### 4. 重复值 (Duplicate Value)

同一个枚举中多个常量使用了相同的值：
- 这是一个错误，需要修正

## 架构设计

### 为什么使用 IDEA 内置 Git 集成？

最初版本插件是自己直接使用 JGit 打开仓库读取内容，这种方式有个问题：需要自己处理认证。当用户使用 SSH 密钥拉代码时，插件无法访问 IDEA 保存的密钥，导致认证失败。

重构后使用 **git4idea**（IDEA 内置的 Git 集成）：

```
┌─────────────────────────────────────────────────────────┐
│  IDEA                                                  │
│  ┌─────────────┐                                      │
│  │ Git4Idea   │  ← 管理仓库、处理认证（SSH/HTTPS/代理）  │
│  └──────┬──────┘                                      │
│         │                                             │
│         ▼                                             │
│  ┌─────────────┐                                      │
│  │ GitService │  ← 本插件获取 GitRepository          │
│  │             │  获取分支列表 → 读取文件内容          │
│  └──────┬──────┘                                      │
│         │                                             │
│         ▼                                             │
│  ┌─────────────┐                                      │
│  │   JGit     │  ← 仅用于读取 blob 内容（无认证）     │
│  └─────────────┘                                      │
└─────────────────────────────────────────────────────────┘
```

**优势：**
- IDEA 能拉代码，插件就能读文件 ✅
- IDEA 支持的认证方式插件都支持 ✅
- 不需要插件维护密钥，更安全 ✅

## 常见问题

### Q: 插件提示 "Not a Git project"

A: 请确保你的项目已经通过 IDEA 启用了 Git 集成。IDEA 左侧项目视图中项目根目录应该显示 Git 图标。

### Q: 我的项目是 SSH 克隆的，插件能访问吗？

A: **可以**！重构后插件完全依赖 IDEA 的 Git 集成，只要 IDEA 能正常拉取代码，插件就能正常读取分支内容。认证都是 IDEA 处理的。

### Q: 支持哪些 Git 托管服务？

A: 任何 IDEA 支持的 Git 服务都支持：GitHub、GitLab、Gitee、GitCat 都可以。

### Q: 实时检查可以关闭吗？

A: 取消勾选 "Enable real-time consistency check" 后点击 OK 即可关闭。或者重新打开对话框取消勾选。

### Q: 扫描很慢吗？

A: 对于包含上百个枚举的项目，扫描通常也只需要数秒时间，扫描在后台进行不会卡住 IDE。
